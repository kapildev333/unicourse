- `httpx.WithUserID(ctx, id)` / `WithUniversityID(ctx, id)` return nothing: they mutate a per-request struct that LogMiddleware puts in ctx (no-op if absent). Call them from auth / tenant middleware; do not reassign ctx.
- `httpx.WithRequestID(ctx, id)` is exported (tests, and any code needing a request id outside the middleware).
- `internal/pg/errors.go` holds only `ErrNotFound`, `ErrConflict`; P0-L2 extends it. `pg` must never import `httpx`.
- Middleware order in main is Recover -> RequestID -> Log (as planned): a panic is answered by Recover (500 envelope, no X-Request-Id header, logged via slog.Error) and produces no request log line.
- `Health` serves /healthz and /readyz from its own mux; main mounts it at "/" and /readyz returns 503 until P0-L2 passes a db ping.
- Validation of body-decoding failures that are not unknown-field use field `body`.
