## Found
- Cross-university reads (SignIn accepting invitations, GET /me) use two extra *SELECT-only* permissive policies keyed on `app.user_id` / `app.email`, set only by a new `pg.WithUserTx` that never sets `app.university_id`. `pg.WithTx` must never set `app.user_id` or `app.email`. Writes stay under `tenant_isolation` only.
- Gotcha (affects every policy): after any `SET LOCAL app.university_id` on a pooled connection, `current_setting('app.university_id', true)` returns `''` (not NULL) in later transactions and `''::uuid` raises 22P02. Every policy must wrap it in `nullif(..., '')`.
## Requests
- to P0-L2: in `0001_init.sql` and `pg`, exactly this (design rationale in docs/design/P1-L1.md §3):
  1. Every `tenant_isolation` policy uses `nullif(current_setting('app.university_id', true), '')::uuid` in both `using` and `with check` (instead of the bare cast).
  2. Three extra policies, after `tenant_isolation`:
     ```sql
     create policy memberships_self on memberships for select
       using (user_id = nullif(current_setting('app.user_id', true), '')::uuid);
     create policy department_admins_self on department_admins for select
       using (user_id = nullif(current_setting('app.user_id', true), '')::uuid);
     create policy invitations_by_email on invitations for select
       using (email = nullif(current_setting('app.email', true), ''));
     ```
  3. New tenant table for pending section staff (Task 10 writes it, auth.SignIn applies it), with `enable`/`force row level security` and the standard `tenant_isolation` policy; include it in the tx_test table list:
     ```sql
     create table pending_section_staff (
       id uuid primary key default gen_random_uuid(),
       university_id uuid not null references universities(id) on delete cascade,
       invitation_id uuid not null references invitations(id) on delete cascade,
       section_id uuid not null references sections(id) on delete cascade,
       role text not null check (role in ('instructor', 'ta')),
       created_at timestamptz not null default now(),
       updated_at timestamptz not null default now(),
       unique (invitation_id, section_id)
     );
     ```
  4. Constraints/indexes auth relies on: `users.email text not null unique check (email = lower(email))`; `users.display_name text not null default ''`; `sessions.token_hash bytea not null unique`; `magic_links.token_hash bytea not null unique`; `invitations.token_hash bytea not null unique`; `magic_links.email` with `check (email = lower(email))`; `invitations.email` with `check (email = lower(email))`; `create index on invitations (email) where accepted_at is null;` `unique (department_id, user_id)` on `department_admins`; `create index on sessions (user_id);` `create index on universities using gin (allowed_email_domains);` token hashes are raw 32-byte SHA-256 (`bytea`), not hex text.
  5. In `pg/tx.go`, alongside WithTx/WithPlatformTx:
     ```go
     // WithUserTx sets app.user_id and/or app.email (empty string = leave unset) and never app.university_id.
     // Only auth uses it: SignIn (email) and GET /me (user id).
     func WithUserTx(ctx context.Context, db *sql.DB, userID, email string, fn func(tx *sql.Tx) error) error
     // SetUniversity runs select set_config('app.university_id', $1, true) inside an open tx.
     // WithTx uses it; auth.SignIn uses it to accept invitations of several universities in one transaction.
     func SetUniversity(ctx context.Context, tx *sql.Tx, universityID string) error
     ```
     Settings via `select set_config($name, $value, true)` (parameterised; `SET LOCAL` cannot take bind parameters).
  6. tx_test additions: inside `WithTx(A)` a user with memberships in A and B sees only A's membership; inside `WithUserTx(u, "")` u sees its own memberships/department_admins in A and B and zero rows of every other tenant table (and zero memberships of other users); inside `WithUserTx("", "x@b.edu")` only invitations with that exact email are visible; an INSERT into memberships inside `WithUserTx` fails (no write path).
