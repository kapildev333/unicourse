## Found
- Surface as built (design P2-L2 §7): `Action` (`Add Exists Invite Error`), `Record`, `Row`, `Preview`, `Verdict`, `Spec`, `Classifier`, `Applier`, `Parse`, `ReadUpload`, `PreviewRows`, `Apply`. Note `csvimport.Error` is an Action constant, not an error type.
- `Parse`/`ReadUpload` errors are `*httpx.Error` validation_failed (field `file`); other errors (classifier mismatch, unknown Action from a classifier, read failures) are plain errors (500).
- Header names lowercased+trimmed; duplicate header names: first wins. Cells trimmed. Data has exactly Required+Optional keys.
- A record is "empty" if all cells are blank after trim (also skips `,,` and whitespace-only lines).
- `PreviewRows` with no non-duplicate records does not call the classifier; `Rows` is never nil. A classifier returning an Action outside the four is an error.
- `Apply` sorts rows by Line before building details and applier input (line order even if Preview.Rows was reordered); empty `formChecksum` is rejected; the checksum is checked before error rows.
- `ReadUpload`: only the first `file` part is used; `checksum` part may come before or after it; body over MaxBytes+1MiB (any part) maps to `file too large`; other multipart syntax errors map to `{file, "invalid multipart upload: ..."}` (not specified in §7, small addition).
- `Key` receives the already-trimmed Data.
