## Review Focus

1. **Boundaries and rounding** — 92.995 is A- (letter on the unrounded value), stored as 93.00; GPA 3.335 → 3.34. Pinned in Task 1.
2. **Finalization is a snapshot** — editing the scale or a score afterwards changes nothing in `final_grades`; reopen deletes and a new finalize recomputes. Pinned in Task 1b.
3. **Students see published only** — an unpublished assessment is absent from `/me/grades` and its score never leaks through `running`. Pinned in Task 1b and Task 2.
4. **Weights** — drafting allows any sum; finalize rejects ≠ 100.00 with field `weights`; a 0-weight assessment is allowed and contributes nothing. Pinned in Task 1a.
5. **Bulk score upsert** — 500 rows in one transaction, a non-enrolled user fails the whole request with the row index. Pinned in Task 1a.
