Builds `apps/api/internal/course` on `tenant.Wrap`/`tenant.Handler`/`authz` (P1-L2 design §1, §2), and fixes the `csvimport` interface of Task 9 (changed, §7). The contract (`openapi.json`, P0-L4 design + orchestrator amendments of 2026-10-06) wins on every shape, status and route.

## 2. Who can do what (truth table)

Section S in department D. "da-in" administers D, "da-out" only D2. Members: instructor/ta/student on S, unrelated member. Lists only ever show rows in the caller's university (RLS).

| Operation | admin | da-in | da-out | instructor S | ta S | student S | unrelated |
|---|---|---|---|---|---|---|---|
| GET /courses (all of the university) | Y | Y | Y | 403 | 403 | 403 | 403 |
| POST/PATCH/DELETE course in D | Y | Y | 403 | 403 | 403 | 403 | 403 |
| GET /sections (all of the university) | Y | Y | Y | 403 | 403 | 403 | 403 |
| GET /sections/{S}, GET /sections/{S}/staff | Y | Y | 403 | Y | Y | Y | 403 |
| POST /sections (course in D), PATCH/DELETE S | Y | Y | 403 | 403 | 403 | 403 | 403 |
| POST staff role `ta` on S, DELETE a `ta` row | Y | Y | 403 | Y | 403 | 403 | 403 |
| POST staff role `instructor`, DELETE an `instructor` row | Y | Y | 403 | 403 | 403 | 403 | 403 |
| GET /sections/{S}/enrollments | Y | Y | 403 | Y | Y | 403 | 403 |
| DELETE enrollment on S | Y | Y | 403 | 403 | 403 | 403 | 403 |
| enrollments import into S | Y | Y | 403 | 403 | 403 | 403 | 403 |
| courses/sections import | Y | Y (rows outside own depts → error rows) | same | 403 | 403 | 403 | 403 |
| GET /me/sections | own | own | own | own | own | own | own (`[]`) |

Decisions: a dept_admin **reads** all courses and sections of the university (catalog and timetable are university-internal; writes stay department-gated). A plain member gets **403** on both list endpoints (`s.Role == authz.Member`); their list is `/me/sections`. Membership role and staff rows are independent (P1-L2 §2): a member who is instructor on S reads S via `CanReadSection`. Smallest rule: list = `s.Role != Member`; item = predicate.

Status order everywhere: 401 → slug 404 → no membership 403 (Wrap) → path id malformed or unknown 404 → predicate 403 → body 400 → write (409/404 from constraints). Exception named per route. Malformed path uuid = unknown id (404), as P1-L2.

## 4. Sections (`section.go`)

One select string, used by list, get, create/patch re-read and my-sections (no N+1; staff and pending staff aggregated per row by correlated subqueries on indexed `section_id`):

```sql
-- sectionCols
s.id, s.course_id, s.term_id, s.number, s.created_at,
c.id, c.department_id, c.code, c.title,
t.id, t.name, to_char(t.starts_on, 'YYYY-MM-DD'), to_char(t.ends_on, 'YYYY-MM-DD'),
coalesce((select json_agg(json_build_object('userId', u.id, 'email', u.email, 'displayName', u.display_name, 'role', ss.role)
                          order by ss.role <> 'instructor', u.email)
          from section_staff ss join users u on u.id = ss.user_id where ss.section_id = s.id), '[]'),
coalesce((select json_agg(json_build_object('email', i.email, 'role', p.role) order by p.role <> 'instructor', i.email)
          from pending_section_staff p join invitations i on i.id = p.invitation_id
          where p.section_id = s.id and i.accepted_at is null and i.expires_at > now()), '[]')
-- sectionFrom
from sections s join courses c on c.id = s.course_id join terms t on t.id = s.term_id
```
`scanSection(scanner) (Section, error)` scans the two json columns into `[]byte` and `json.Unmarshal`s into `[]Staff` / `[]PendingStaff` (keys match the tags). Extra trailing columns (my-sections' `my_role`) are scanned by passing extra dests: signature `scanSection(sc interface{ Scan(...any) error }, extra ...any)`.

Validation: `courseId`, `termId` uuid (`"is required"` / `"must be a uuid"`); `number` = `TrimLen("number", v, 20)`.

| Route | Steps | Result |
|---|---|---|
| GET `/sections?termId=&courseId=` | member → 403; bad uuid filter → 400 `{termId|courseId, "must be a uuid"}` (both collected); `select sectionCols sectionFrom where ($4::uuid is null or s.term_id=$4) and ($5::uuid is null or s.course_id=$5) and ($1::timestamptz is null or (s.created_at, s.id) > ($1, $2::uuid)) order by s.created_at, s.id limit $3` | 200 `SectionList` |
| GET `/sections/{id}` | `… where s.id=$1` → 404 "section"; `!CanReadSection` → 403 | 200 `Section` |
| POST `/sections` | member → 403; validate → 400; `select department_id from courses where id=$1` → 404 "course"; `!CanManageDepartment` → 403; `insert into sections (university_id, course_id, term_id, number) values (…) returning id`; MapError: ErrNotFound → `NotFound("term")`, ErrConflict → `Conflict("section number already exists for this course and term")`; re-read by id | 201 `Section`; audit `section.create` after `sectionAudit` |
| PATCH `/sections/{id}` | `select s.id, s.course_id, s.term_id, s.number, c.department_id from sections s join courses c on c.id=s.course_id where s.id=$1 for update of s` → 404; `!CanManageDepartment` → 403; only `number` (none → `NoFields`); update; conflict as POST; re-read | 200; audit `section.update` before/after `sectionAudit` |
| DELETE `/sections/{id}` | load as PATCH (404/403); `delete from sections where id=$1` (staff, enrollments, pending rows cascade, D15) | 204 (never 409); audit `section.delete` before |

Ceiling: the cascade removes staff/enrollment rows without their own audit rows; the section's `before` is the record. Accepted.

## 5. Staff (`staff.go`)

Shared `resolveEmails(ctx, tx, emails []string) (map[string]emailState, error)` (one query, used here and by both staff-bearing imports and the roster):
```go
type emailState struct { UserID, DisplayName, Status, InvitationID string } // Status "" (no membership) | "active" | "invited"
```
```sql
select e.email, coalesce(u.id::text, ''), coalesce(u.display_name, ''), coalesce(m.status, ''),
       coalesce((select i.id::text from invitations i where i.email = e.email and i.accepted_at is null
                 and i.expires_at > now() order by i.created_at desc limit 1), '')
from unnest($1::text[]) as e(email)
left join users u on u.email = e.email
left join memberships m on m.user_id = u.id
```
(memberships/invitations are RLS-confined to this university; `users` has no RLS.)

| Route | Steps | Result |
|---|---|---|
| GET `/sections/{id}/staff` | section exists (`select 1 from sections where id=$1`) → 404; `!CanReadSection` → 403; `select u.id, u.email, u.display_name, ss.role, ss.created_at, ss.id from section_staff ss join users u on u.id=ss.user_id where ss.section_id=$4 and <keyset on ss.created_at, ss.id>` | 200 `SectionStaffList` (accepted staff only; pending staff are on `Section.pendingStaff`) |
| POST `/sections/{id}/staff` | 404 section; `!CanManageTAs` → 403; decode `{email, role}`: `auth.NormalizeEmail` else `{email, "must be a valid email"}`, role not `instructor`/`ta` → `{role, "must be one of instructor, ta"}` → 400; role `instructor` and `!CanManageSection` → 403; `st := resolveEmails([email])[email]`; then case below | |
| ↳ `st.Status == "active"` | `insert into section_staff (university_id, section_id, user_id, role) values (…) returning id`; ErrConflict → `Conflict("user is already staff on this section")` | 201 `SectionStaff`; audit `staff.create` (entityId = `section_staff.id`) after `staffAudit` |
| ↳ `st.Status == "invited"` | `Conflict("user is already a member")` (`tenant.ErrAlreadyMember`) | 409 |
| ↳ no membership, `st.InvitationID != ""` | insert pending row (below) on that invitation; select the invitation (as `tenant` lists it) | 202 `StaffInvited` |
| ↳ no membership, no invitation | `tenant.CreateInvitation(ctx, tx, tenant.NewInvitation{UniversityID, ActorUserID: s.UserID, Email, Role: authz.Member}, d.Mailer, d.BaseURL)`; insert pending row | 202 `StaffInvited` |
| DELETE `/sections/{id}/staff/{userId}` | 404 section; `!CanManageTAs` → 403; userId not uuid → 404 "staff"; `select ss.id, ss.role, u.email from section_staff ss join users u on u.id=ss.user_id where ss.section_id=$1 and ss.user_id=$2 for update of ss` → 404 "staff"; row role `instructor` and `!CanManageSection` → 403; `delete from section_staff where id=$1` | 204; audit `staff.delete` before `staffAudit` |

Pending row: `insert into pending_section_staff (university_id, invitation_id, section_id, role) values ($1,$2,$3,$4)`; ErrConflict → `Conflict("invitation already pending for this section")`. Not separately audited (the invitation's audit row is the record; ceiling: re-attaching to an existing invitation leaves no audit row — accepted).

Rules decided: no domain check on staff add — the invitation itself authorises sign-in (spec §5: domain allowed **or** pending invitation for that exact email; P1-L1 §7). Instructors may thereby invite outside emails as `member` (escalated, §12). An instructor cannot remove themselves (their row is `instructor` → needs `CanManageSection`); a TA cannot remove anything. Pending staff are **not** addressable by `DELETE …/staff/{userId}` (no user id); ceiling: revoking the invitation (`DELETE /invitations/{id}`) removes them by cascade, including that invitation's pending rows on other sections. Accepted until a UI needs per-section pending removal (then add `DELETE …/sections/{id}/pending-staff/{invitationId}`).

## 7. `csvimport` (Task 9, interface replaced; P2-L1 builds this version)

```go
package csvimport
type Action string // Add "add", Exists "exists", Invite "invite", Error "error"
type Record struct { Line int; Data map[string]string } // Line = csv.Reader.FieldPos(0) line of the record (correct with quoted newlines)
type Row struct { Line int `json:"line"`; Action Action `json:"action"`; Message string `json:"message,omitempty"`; Data map[string]string `json:"data"`; Ref any `json:"-"` }
type Preview struct { Checksum string `json:"checksum"`; Rows []Row `json:"rows"`; Counts map[Action]int `json:"counts"` } // Counts has all four keys
type Verdict struct { Action Action; Message string; Ref any } // Ref: classifier's resolution, handed back to the Applier
type Spec struct {
    Required, Optional []string        // lowercased header names
    MaxBytes int64                     // 0 → 5 << 20
    Key func(data map[string]string) string // duplicate key; nil → Required values joined by "\x00"
}
// Classifier sees every non-duplicate record once, in line order; returns one Verdict per record. Must not write.
type Classifier func(ctx context.Context, tx *sql.Tx, recs []Record) ([]Verdict, error)
// Applier receives all Add and Invite rows (line order) once; not called when there are none.
type Applier func(ctx context.Context, tx *sql.Tx, rows []Row) error

func Parse(r io.Reader, s Spec) (recs []Record, checksum string, err error)
func ReadUpload(r *http.Request, s Spec) (recs []Record, checksum, formChecksum string, err error)
func PreviewRows(ctx context.Context, tx *sql.Tx, recs []Record, checksum string, s Spec, c Classifier) (Preview, error)
func Apply(ctx context.Context, tx *sql.Tx, p Preview, formChecksum string, a Applier) error
```
- `Parse`: read all of `io.LimitReader(r, MaxBytes+1)`; longer than MaxBytes → `{file, "file too large"}`; sha256 hex of the raw bytes; strip leading UTF-8 BOM; `encoding/csv` (default `FieldsPerRecord` = header count, `TrimLeadingSpace` false, CRLF handled by the reader); cells `strings.TrimSpace`; no header → `{file, "header row required"}`; header cells lowercased; each missing Required column → `{file, "missing column <name>"}` (all collected); csv syntax error → `{file, "line <n>: <err>"}`; a record whose cells are all empty is skipped (trailing `,,` lines; true blank lines are skipped by `encoding/csv`). `Data` holds exactly Required+Optional keys (absent optional → `""`); unknown columns ignored. Header-only → zero records, no error.
- `ReadUpload`: not `multipart/form-data` → `{file, "must be a multipart/form-data upload"}`; `r.Body = http.MaxBytesReader(nil, r.Body, MaxBytes+1<<20)`; stream `r.MultipartReader()` parts (no temp files): `file` → `Parse(part, s)`; `checksum` → first 128 bytes, trimmed; others ignored. No `file` part → `{file, "is required"}`.
- `PreviewRows`: duplicates by `Key` → `Error`, message `"duplicate of line <first>"`, not sent to the classifier; others → one classifier call; verdict count mismatch → error (500).
- `Apply`: `formChecksum != p.Checksum` → `httpx.Validation({checksum, "file changed since preview"})` (missing checksum included); any `Error` row → `httpx.Validation` with one `{field: "line:<n>", message}` per error row, in line order; else `a(ctx, tx, add+invite rows)`.
- Tests (Task 9 Step 1, unchanged intent): bom-crlf, quoted comma, header-only, dupes ("duplicate of line 2"), missing column, too large, stale checksum (applier not called), applier failure rolls back; plus `Key` normalising case (`Alice@A.edu` / `alice@a.edu ` → duplicate).

## 8. The three imports (`import.go`)

Handler shape (all six routes): auth check → `ReadUpload` → `PreviewRows` → preview route returns 200 `Preview`; import route calls `Apply` then returns 200 the same `Preview` (contract decision 10). Preview runs in the request's tenant tx and writes nothing; import re-classifies in its own tx (state may have changed; the checksum binds the file, not the verdicts — a row that became `exists` is simply skipped).

Emails in cells: `auth.NormalizeEmail` (Review Focus 1). Error messages below are exact.

### 8.1 Enrollments `POST /sections/{id}/enrollments/import[/preview]`
Auth: section 404; `!CanManageSection` → 403. Spec: Required `email`, Optional `displayname`; `Key` = normalised email (raw lowercased+trimmed if invalid). `displayname` is accepted and ignored (users get their name at sign-in; ceiling).
Classifier: invalid → `error "invalid email"`. `resolveEmails(valid)`; plus `select user_id from enrollments where section_id=$1 and user_id = any($2::uuid[])` and `select pe.invitation_id from pending_enrollments pe where pe.section_id=$1 and pe.invitation_id = any($2::uuid[])`; `select to_json(allowed_email_domains) from universities where id=$1`. Per row:
1. `active`: enrolled → `exists`; else `add` (Ref userID, email).
2. `invited` → `error "membership is not active"`.
3. pending invitation: pending enrollment exists → `exists`; else `invite` (Ref invitationID).
4. domain (after `@`) in allowed → `invite` (Ref new).
5. else `error "domain not allowed"`.
Applier: `insert into enrollments (university_id, section_id, user_id) select $1, $2, u from unnest($3::uuid[]) u on conflict (section_id, user_id) do nothing returning id, user_id` → `audit.WriteMany` `enrollment.create` after `enrollmentAudit`. New invites: `tenant.CreateInvitations(…, emails, authz.Member)`; then `insert into pending_enrollments (university_id, invitation_id, section_id) select $1, i, $2 from unnest($3::uuid[]) i on conflict do nothing` for new + existing invitation ids.

### 8.2 Courses `POST /courses/import[/preview]`
Auth: member → 403. Required `departmentcode, code, title`; Key = trimmed `code`.
Classifier: `select code, id from departments`; `select code from courses where code = any($1)`. Per row, first match: empty code/title → `error "code is required"` / `"title is required"`; over 20/200 runes → `"code must be at most 20 characters"` / `"title must be at most 200 characters"`; unknown → `"unknown department code <X>"`; `!CanManageDepartment` → `"department <X> is not managed by you"`; code exists → `exists` (never updates title; ceiling); else `add`.
Applier: `insert into courses (university_id, department_id, code, title) select $1, d, c, t from unnest($2::uuid[], $3::text[], $4::text[]) as x(d, c, t) returning id, department_id, code, title, created_at` → `WriteMany` `course.create` after `Course`. A concurrent create → 23505 → whole import 409 `"course code already exists"`.

### 8.3 Sections `POST /sections/import[/preview]`
Auth: member → 403. Required `coursecode, termname, number`; Optional `instructoremails, taemails`; Key = the three trimmed values.
Classifier: split each email cell on `;`, trim, drop empty, normalise; `select code, id, department_id from courses where code = any($1)`; `select name, id from terms where name = any($2)` (D18); existing sections: `select s.id, s.course_id, s.term_id, s.number from sections s join unnest($1::uuid[], $2::uuid[], $3::text[]) as x(c, t, n) on s.course_id = x.c and s.term_id = x.t and s.number = x.n`; existing staff `select section_id, user_id from section_staff where section_id = any($1)`; existing pending `select section_id, invitation_id from pending_section_staff where section_id = any($1)`; `resolveEmails(all)`. Per row, first error wins: `"number is required"`, `"number must be at most 20 characters"`, `"unknown course code <X>"`, `"unknown term <X>"`, `"course <X> is not in a department you manage"`, `"invalid email <raw>"`, `"<email> listed as both instructor and ta"`, `"<email>: membership is not active"`. Otherwise: any email needing an invitation (new or attach to pending, not already pending on this section) → `invite`; else section new or any staff to add → `add`; else `exists`. No domain rule (same as staff add, §5). An existing staff member listed with another role keeps their role.
Applier: new sections `insert … select from unnest(course_ids, term_ids, numbers) returning id, course_id, term_id, number` → `WriteMany` `section.create`; staff `insert into section_staff … select from unnest(section_ids, user_ids, roles) on conflict (section_id, user_id) do nothing returning id, section_id, user_id, role` → `WriteMany` `staff.create`; new emails (deduped across rows) → `tenant.CreateInvitations(member)`; pending `insert into pending_section_staff … select from unnest(invitation_ids, section_ids, roles) on conflict (invitation_id, section_id) do nothing`. Row line → section id map kept in the applier.

### 8.4 `tenant.CreateInvitations` (added by this lane to `tenant/invitation.go`)

### 8.5 `audit.WriteMany` (in `internal/audit`; see §12 for ownership)
```go
func WriteMany(ctx context.Context, tx *sql.Tx, universityID string, es []Entry) error // no-op on empty
```
Marshal each Before/After as `Write` does (nil → SQL NULL), then one statement: `insert into audit_log (university_id, actor_user_id, action, entity_type, entity_id, before, after) select $1, nullif(a, '')::uuid, ac, et, eid::uuid, b::jsonb, af::jsonb from unnest($2::text[], $3::text[], $4::text[], $5::text[], $6::text[], $7::text[]) as x(a, ac, et, eid, b, af)` (nil payload → nil element in a `[]*string`). Test: 3 entries land, one with nil Before.

### 8.6 Performance (50k-row roster, ~3 MB)
Parse: ms. Classify: 4 statements (arrays are single parameters, no 65535-parameter limit). Apply (all existing members): 1 insert + 1 audit insert. All-new students: 1 invitation insert + 1 audit + 1 pending insert **+ 50k `Mailer.Send` inside the tx**.
