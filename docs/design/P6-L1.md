## 0. Decisions, deviations and simplifications

| # | Decision | Why / ceiling |

### 1.3 Measuring script (for the reviewer's three re-measurements)

```python
def lum(h):
    c = [int(h.lstrip('#')[i:i+2], 16) / 255 for i in (0, 2, 4)]
    c = [x / 12.92 if x <= 0.04045 else ((x + 0.055) / 1.055) ** 2.4 for x in c]
    return 0.2126 * c[0] + 0.7152 * c[1] + 0.0722 * c[2]
def ratio(a, b):
    x, y = sorted([lum(a), lum(b)], reverse=True)
    return (x + 0.05) / (y + 0.05)
print(round(ratio('#425a7d', '#eef4ed'), 2))  # 6.29
```

## 3. Theme: `src/lib/theme.ts`, `public/theme-boot.js`, `index.html` (P6-L1a)

```ts
// src/lib/theme.ts
export type ThemeChoice = 'system' | 'light' | 'dark'
export const themeKey = 'unicourse:theme'

/** Stored choice; anything else (absent, garbage, storage blocked) is 'system'. */
export function read(): ThemeChoice {
  try {
    const v = localStorage.getItem(themeKey)
    return v === 'light' || v === 'dark' ? v : 'system'
  } catch {
    return 'system'
  }
}
/** 'system' removes the key. Storage failures are ignored: the choice then lasts for this page only. */
export function write(choice: ThemeChoice): void
/** 'system' removes data-theme (CSS follows prefers-color-scheme); otherwise sets it. */
export function apply(choice: ThemeChoice, root: HTMLElement = document.documentElement): void
/** apply(read()). public/theme-boot.js is this function, hand-minified; keep them in step. */
export function boot(): void
```

`public/theme-boot.js` (served at `/theme-boot.js`; Vite copies `public/` to `dist/` as is; not linted, ESLint only matches `*.ts(x)`):


## 7. Literal-colour gate: `src/no-literal-colors.test.ts` (P6-L1a)

Scans every `.ts` and `.tsx` under `src/` except tests (spec §8; `index.css` is not a `.ts(x)` file and is the one place literals live). Generated files are scanned too (`api/types.ts`, `routeTree.gen.ts` have no hits today).

```ts
import { expect, it } from 'vitest'

const files = import.meta.glob<string>(['./**/*.{ts,tsx}', '!./**/*.test.{ts,tsx}'], { query: '?raw', import: 'default', eager: true })

const palette = 'slate|gray|zinc|neutral|stone|red|orange|amber|yellow|lime|green|emerald|teal|cyan|sky|blue|indigo|violet|purple|fuchsia|pink|rose'
const rules: [string, RegExp][] = [
  ['hex colour', /(?<![\w&])#(?:[0-9a-fA-F]{3,4}|[0-9a-fA-F]{6}|[0-9a-fA-F]{8})\b/],
  ['white/black utility', /\b[a-z-]+-(?:white|black)\b/],
  ['Tailwind palette utility', new RegExp(`\\b[a-z-]+-(?:${palette})-(?:50|[1-9]00|950)\\b`)],
  ['dark: variant', /(?:^|[\s'"`{:])dark:/],
  ['arbitrary named colour', /-\[(?:white|black)\]/],
  ['colour function', /\b(?:rgba?|hsla?|oklch|oklab|lab|lch)\(/],
]

it('uses colour tokens only', () => {
  const hits: string[] = []
  for (const [file, src] of Object.entries(files))
    src.split('\n').forEach((line, i) => {
      for (const [name, re] of rules) if (re.test(line)) hits.push(`${file}:${i + 1} ${name}: ${line.trim()}`)
    })
  expect(hits).toEqual([])
})

it('scans the tree and every rule can fire', () => {
  expect(Object.keys(files).length).toBeGreaterThan(50)
  // built by concatenation so Tailwind's source scan finds no utility in this file
  const bad = ["'#b54708'", 'bg-' + 'white', 'text-slate-' + '500', '"dark' + ':bg-surface"', 'md:dark' + ':bg-canvas', 'bg-[' + 'white]', 'rgb(0 0 0)']
  const names = rules.map(([n]) => n)
  const hit = (s: string) => rules.filter(([, re]) => re.test(s)).map(([n]) => n)
  expect(hit(bad[0])).toContain(names[0])
  expect(hit(bad[1])).toContain(names[1])
  expect(hit(bad[2])).toContain(names[2])
  expect(hit(bad[3])).toContain(names[3])
  expect(hit(bad[4])).toContain(names[3]) // stacked variant
  expect(hit(bad[5])).toContain(names[4])
  expect(hit(bad[6])).toContain(names[5])
})
```
Regexes without the `g` flag (stateless `test`). Today the gate fails only on `badge.tsx` (3 hex) and `button.tsx` (`text-white` x2); P6-L1a fixes both. Ceiling: a colour built at runtime from strings (`'#' + x`) escapes it; the reviewer greps (§10).

## 12. Open risks

- **Tailwind variant interplay** (`not-aria-pressed:hover:`, `hover:not-aria-invalid:`, `aria-invalid:`): built-in in Tailwind v4.1+, which the project has (4.3). If one does not compile, the worker reports rather than substituting a different rule.
- **`@theme static` + `--color-*: initial`** removes `bg-white`-style utilities silently. Any missed literal in a feature file renders unstyled until its task lands; the gate test fails first, so CI catches it.
- **Light hairline weight** (decision 5) and **Powder primary button in dark** (decision 2) are visible deviations from the spec's role table; both are measured and argued, and the Task 6 screenshots are where the owner judges them.
- The boot script's cache: `/theme-boot.js` is outside `assets/`, so it gets no immutable caching; a change to it reaches browsers on the next revalidation (`Last-Modified`), which is fine for a two-line file.
