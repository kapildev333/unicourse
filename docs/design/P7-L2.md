## 2. Pure logic (`features/grades/grade.ts`)

```ts
export type Access = { view: boolean; scores: boolean; assessments: boolean; finalize: boolean }
export function gradebookAccess(m: MyMembership, userId: string, section: Section): Access {
  const { manager, staffRole } = sectionAccess(m, userId, section)
  const instructor = staffRole === 'instructor'
  return { view: manager || !!staffRole, scores: instructor || staffRole === 'ta', assessments: instructor, finalize: instructor || manager }
}

/** Half up to 2 decimals; toFixed(6) absorbs binary error (92.995*100 = 9299.4999…). */
export const round2 = (x: number) => Math.round(Number((x * 100).toFixed(6))) / 100
export const fmt2 = (x: number) => round2(x).toFixed(2)          // percents, GPA, grade points
export const fmt1 = (x: number) => x.toFixed(1)                  // credits
export const fmtNum = (x: number) => String(Number(x.toFixed(2))) // 40, 87.5: weights, max, scores

const decimal = /^\d+(\.\d{1,2})?$/
/** Parses a typed score. '' -> null (clear). */
export function parsePoints(text: string, maxPoints: number): { points: number | null } | { error: string } {
  const t = text.trim()
  if (t === '') return { points: null }
  if (!decimal.test(t)) return { error: 'Enter a number like 42 or 42.5.' }
  const n = Number(t)
  if (n > 2 * maxPoints) return { error: `Enter at most ${fmtNum(2 * maxPoints)} (twice the maximum).` }
  return { points: n }
}
/** '' or not /^\d+(\.\d{1,2})?$/ -> undefined */
export function parseDecimal(text: string): number | undefined

/** Scale row with the greatest minPercent <= percent (unrounded); undefined below every row. */
export function letterFor(rows: GradeScaleRow[], percent: number): GradeScaleRow | undefined

export function weightTotal(as: Pick<Assessment, 'weight'>[]): number      // round2 of the sum
export const totalsHundred = (as: Pick<Assessment, 'weight'>[]) => weightTotal(as) === 100

/** Finalization percent: missing scores count as 0; divisor = sum of weights (finalize requires 100). */
export function finalPercent(as: Assessment[], scores: Record<string, number>): { percent: number; missing: number }
  // percent = Σ(weight × (scores[id] ?? 0) / maxPoints) / Σweight × 100 ... (0 when Σweight = 0); missing = count of as without a score

export type ScaleErrors = { rows: Record<number, Partial<Record<'letter' | 'minPercent' | 'points', string>>>; table?: string }
/** Client checks before PUT; empty result = valid. Rows are the editor's strings. */
export function validateScale(rows: { letter: string; minPercent: string; points: string }[]): ScaleErrors
```

### 3.2 Score cell (`score-cell.tsx`)

```ts
export type CellStatus = 'idle' | 'pending' | 'saved' | 'error'
export type Cell = { draft: string; sent?: string; status: CellStatus; message?: string }

export function ScoreCell(props: {
  label: string          // "Score for Erin Moe, Midterm"
  row: number; col: number
  value: string          // cell.draft if a Cell exists, else server text (fmtNum(points) or '')
  status: CellStatus; message?: string
  onChange(text: string): void
  onCommit(): void       // blur
  onRevert(): void       // Escape
  onPasteLines(lines: string[]): void
}): JSX.Element          // renders the <td>

/** Focus and select the input at (row, col) inside `table`, if any. */
export function focusCell(table: Element | null, row: number, col: number): void
```

Markup (`td className="text-right"`):
`<input type="text" inputMode="decimal" autoComplete="off" data-row data-col aria-label={label} aria-invalid={status==='error' || undefined} aria-describedby={status==='error' ? msgId : undefined} className={cellInput} />` with
`cellInput = 'h-8 w-20 rounded border border-line-strong bg-surface px-2 text-right text-sm text-ink focus-visible:outline-2 focus-visible:outline-offset-1 focus-visible:outline-focus aria-[invalid=true]:border-danger'` (own string: overriding `inputClass`'s `h-9 w-full` by appending classes is order-dependent in Tailwind).
Below the input, at most one line: `pending` → `<p className="mt-1 text-xs text-ink-muted">Saving…</p>`; `saved` → `<p className="mt-1 text-xs text-success">Saved</p>`; `error` → `<p id={msgId} className="mt-1 ml-auto max-w-40 text-xs text-danger">{message}</p>`. Read-only viewers (`!access.scores`) get a plain `td` with `fmtNum(points)` or `—` plus `<span className="sr-only">No score</span>`.

Keys (`onKeyDown`; `table = e.currentTarget.closest('table')`):

| Key | Effect |
|---|---|
| Tab / Shift+Tab | native (row-major through the inputs) |
| Enter, ArrowDown | `preventDefault`; `focusCell(table, row + 1, col)` |
| Shift+Enter, ArrowUp | `preventDefault`; `focusCell(table, row - 1, col)` |
| ArrowLeft with a collapsed caret at 0 | `preventDefault`; `focusCell(table, row, col - 1)` |
| ArrowRight with a collapsed caret at the end | `preventDefault`; `focusCell(table, row, col + 1)` |
| Escape | `onRevert()` |

`onFocus` selects the input's text (typing replaces). Moving focus blurs, which commits. `onPaste`: `text = clipboardData.getData('text')`; `lines = text.split(/\r?\n/)`, drop one trailing `''`; if `lines.length < 2` let the default paste happen; else `preventDefault()` and `onPasteLines(lines.map(l => l.split('\t')[0].trim()))`.

### 3.3 Save behaviour (in `gradebook.tsx`)

State: `const [cells, setCells] = useState<Record<string, Cell>>({})`, key `${userId}:${assessmentId}`. `serverText(s, a) = s.scores[a.id] === undefined ? '' : fmtNum(s.scores[a.id])`.

- `onChange(text)`: `cells[k] = { draft: text, sent: cells[k]?.sent, status: 'idle' }`.
- `onRevert()`: if `cells[k]?.status !== 'pending'`, delete `cells[k]`.
- `onCommit()`: `c = cells[k]`; nothing if `!c` or `c.status === 'pending'` or `c.draft === (c.sent ?? serverText)`; if `c.draft === serverText` and no `sent`, delete `cells[k]` and stop; else `save(a, [{ student, text: c.draft }])`.
- `onPasteLines(lines)` on (row, col): for `i` in lines: target row `row + i`; beyond the last student → count as dropped; blank → skip; else set `cells[k].draft = lines[i]` and add to the batch. Then `save(a, batch)`. Dropped > 0 → announce `{n} pasted values didn't fit below the last student and were ignored.`
- `save(a, entries)`:
  1. Parse each with `parsePoints(text, a.maxPoints)`. Errors → `cells[k] = { draft, status: 'error', message }` (no request). Clearing (`null`) where `serverText === ''` → delete the cell, not sent. Clearing when `ScoresPut` does not allow `null` → error per §0 #8.
  2. Nothing left → stop (announce the first error as below).
  3. Delete every cell whose status is `saved` (new batch, §0 #5). Mark the batch `pending`, `sent = draft`.
  4. `putScores` in chunks of 500, sequentially, `{ userId, points }` in batch order.
  5. Success: batch → `saved`; announce `Saved: {name}, {assessment}.` (one) or `Saved {n} scores for {assessment}.`; `await refreshGrades()`.
  6. Failure `e`: `sent = undefined` for the batch (so the next blur retries). If `validation_failed`, for each detail matching `/^scores\[(\d+)\]\.(\w+)$/` map the index to the batch row and set `message = copy['validation_failed:' + field] ?? sentence(d.message)`; batch rows without a detail get `Not saved: another score in this paste has an error.` Otherwise every batch row gets `Not saved.` and the page `ErrorBanner` shows `errorMessage(e, copy)`. Announce `Not saved: {name}, {assessment}. {message}` (first row) or `{n} scores not saved for {assessment}.`
- Focus is **not** moved on a cell error (the user is moving through cells); the message is announced and `aria-invalid` + `aria-describedby` are set.

## 8. Tests (vitest + Testing Library + `mockApi`, `fireEvent` only: no user-event in the project)

Page tests use the harness of `section-detail.test.tsx` (QueryClient with `['me']` preset, memory router with a `$slug` route). Unmatched requests fail loudly in `mockApi`, which makes "calls nothing else" assertions real.

**`grade.test.ts`**
1. `gradebookAccess`: instructor all true; TA `scores` only; admin `view, finalize`; dept_admin own department `view, finalize`; dept_admin other department and plain member all false.
2. `round2`/`fmt2`: 92.995 → `93.00`; 3.335 → `3.34`; 2.5 → `2.50`.
3. `letterFor` on `usPreset`: 92.99 → A-, 93 → A, 92.995 → A- (unrounded), 0 → F, 100 → A; a scale without a 0 row and 10 → undefined.
4. `parsePoints` (max 40): `''` → null, `'34'`, `'34.5'`, `'80'` ok; `'34.555'`, `'-1'`, `'abc'`, `'3,5'` → number error; `'80.01'` → "Enter at most 80 (twice the maximum)."

## 10. Requests to P7-L1 (also in `.claude/lanes/P7-L2.md`)

- **R1** Decimals (`credits`, `minPercent`, `points`, `maxPoints`, `weight`, `percent`, `gpa`, `mean`, `median`) are JSON **numbers**, not strings.
- **R2** `PUT …/scores` accepts `points: null` to remove a score (one request for "clear this cell"). Fallback in §0 #8 if not.
- **R3** Scores import uses its own schemas (`ScoreImportRow.action: 'add'|'update'|'error'`, counts `{ add, update, error }`), so `ImportRow`/`ImportCounts` and Phase 6's `csv-import-dialog.tsx`/`ActionBadge` keep typechecking.
- **R4** `openapi.json` declares `text/csv` as a second 200 content type of `GET …/gradebook`.
- **R5** `GradebookStudent.final` = `FinalGrade` including `overrideReason?`.
- **R6** `/me/grades`: `term` is the `Term` schema (needs `startsOn`); `section` has `id`, `number`; `course` has `id`, `code`, `title`; `terms[].credits` and `cumulativeCredits` are the credits of `graded` final grades (the GPA denominator).
- **R7** Detail field names exactly: `scores[i].points|userId`, `rows[i].letter|minPercent|points`, `rows`, `overrides[i].letter|status|reason`, `weights`, `name`, `maxPoints`, `weight`, `dueOn`, `letter`, `reason`; duplicate assessment name is `409 conflict` with field `name` or none.
- **R8** `AssessmentUpdate.dueOn` accepts `null` to clear.
