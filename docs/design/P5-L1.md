# P5-L1 design: meetings in the API, catalog reads, sections-import `meetings` column

Source: spec `docs/specs/2026-10-06-student-schedule.md` §3, §4, §5, §7 (binding); plan Task 1 and Review Focus 1, 2, 3, 5; PLAN.md D16, D19, D20, D22, D31, D34-D40. Builds on `docs/design/P2-L2.md` (course package) and `docs/design/P0-L4.md` (contract conventions). Where this document and the existing code disagree on a convention, the existing code wins; where they disagree on behaviour, this document wins.

## 0. Decisions taken here

| # | Decision | Why |
|---|---|---|
| 1 | Meetings join the shared section SELECT as a third `json_agg` correlated subquery in `sectionCols` (not a second query per page). | `staff` and `pendingStaff` already work this way; every reader (`readSection`, `listSections`, `getMySections`) gets meetings with zero call-site changes beyond `scanSection`; one round trip, index on `section_meetings(section_id)`. |
| 2 | `Meeting` = `{ id } + MeetingInput` (Go embedding). Audit payloads carry `MeetingInput` (no ids). | Ids change on every replace; audit diffs stay readable. |
| 3 | `PATCH` decodes `meetings` into `*[]MeetingInput`: absent and JSON `null` both mean "keep"; `[]` clears. | Keeps `DecodeJSON`'s unknown-field rejection inside meeting rows. Ceiling: `null` cannot be told from absent; typed clients never send it. A body of only `{"meetings":null}` is `400 no fields to update`. |
| 4 | Validation reports all errors at once: `sectionFields` changes to return `[]httpx.FieldError`, meeting errors are appended. | Same as `courseFields`. |
| 5 | `GET /sections/{id}` opens to every active member too (spec §4 names only the lists). **Escalated.** | Spec §6: a catalog row links to the section page; without this a student opening a section they are not in gets 403. Rosters (`/enrollments`) and `/staff` stay as they are. |
| 6 | `pendingStaff` masking rule (one helper, three call sites): list = `[]` for every plain member; get = `[]` for a plain member who is not staff on that section; `/me/sections` = `[]` on rows where a plain member's `myRole` is `student`. Admin and dept_admin (any department) always see it. | Plan's per-row-cost argument for the list; staff of a section keep seeing pending TAs they invited (the staff editor uses `GET /sections/{id}`). |
| 7 | L1a lands every type-affecting contract change **and** implements it (meetings, `q`, `departmentId`); L1b lands member reads, masking, the `Who:` text, and the import column with its description. | Every contract line on `main` is implemented when it lands; the web lane gets all types from L1a. |
| 8 | `q` uses Postgres's default ILIKE escape (backslash); no `ESCAPE` clause. No trigram index. | Smallest. Ceiling in §9. |
| 9 | Import: a slot cell for an existing section that already has meetings is reported, not applied, even when identical: `Exists` with message `section exists; keeps meetings`. | D31/D39; no equality check to write. |

## 1. Migration `apps/api/migrations/0002_section_meetings.sql` (L1a)

`pg.Migrate` runs each file in its own transaction; the file is plain SQL, no `begin`/`commit`.

```sql
-- Spec 2 §3: weekly meeting slots of a section (1 = Monday ... 7 = Sunday, ISO).
-- Times are wall-clock in the university's timezone; nothing converts them.
create table section_meetings (
  id uuid primary key default gen_random_uuid(),
  university_id uuid not null references universities(id) on delete cascade,
  section_id uuid not null,
  weekday smallint not null check (weekday between 1 and 7),
  starts_at time not null,
  ends_at time not null,
  location text not null default '' check (char_length(location) <= 100),
  created_at timestamptz not null default now(),
  updated_at timestamptz not null default now(),
  check (starts_at < ends_at),
  foreign key (university_id, section_id) references sections (university_id, id) on delete cascade
);
create index on section_meetings (section_id);

alter table section_meetings enable row level security;
alter table section_meetings force row level security;
create policy tenant_isolation on section_meetings
  using (university_id = nullif(current_setting('app.university_id', true), '')::uuid)
  with check (university_id = nullif(current_setting('app.university_id', true), '')::uuid);

create trigger section_meetings_set_updated_at before update on section_meetings for each row execute function set_updated_at();
```

No `(university_id, created_at, id)` index: meetings are never paged.

## 3. `apps/api/internal/course/meeting.go` (new, L1a; `parseSlots` L1b)

```go
const maxMeetings = 20

// MeetingInput is one weekly slot as written (request body, import cell, audit payload).
type MeetingInput struct {
	Weekday  int    `json:"weekday"`
	StartsAt string `json:"startsAt"`
	EndsAt   string `json:"endsAt"`
	Location string `json:"location"`
}

// Meeting is the contract resource.
type Meeting struct {
	ID string `json:"id"`
	MeetingInput
}

// meetingsJSON aggregates a section's meetings; s is the sections alias. Used by sectionCols and loadForWrite.
const meetingsJSON = `coalesce((select json_agg(json_build_object('id', m.id, 'weekday', m.weekday,
	'startsAt', to_char(m.starts_at, 'HH24:MI'), 'endsAt', to_char(m.ends_at, 'HH24:MI'), 'location', m.location)
	order by m.weekday, m.starts_at, m.ends_at, m.location)
	from section_meetings m where m.section_id = s.id), '[]')`

func hm(s string) bool // len(s) == 5 && time.Parse("15:04", s) succeeds

// checkMeeting trims location and returns errors with bare field names (weekday, startsAt, endsAt, location), in that order.
func checkMeeting(m MeetingInput) (MeetingInput, []httpx.FieldError)

// validateMeetings checks a request list: over 20 rows is one error {meetings, "must have at most 20 entries"}
// (rows not checked); otherwise row errors prefixed "meetings[<i>]." (0-based). Returns the trimmed rows, sorted; never nil.
func validateMeetings(in []MeetingInput) ([]MeetingInput, []httpx.FieldError)

func sortMeetings(ms []MeetingInput) // slices.SortFunc by weekday, startsAt, endsAt, location (HH:MM sorts as text)

// insertMeetings inserts ms[i] for section secs[i] in one statement; no-op when empty.
func insertMeetings(ctx context.Context, tx *sql.Tx, uni string, secs []string, ms []MeetingInput) error

// replaceMeetings deletes the section's meetings and inserts ms (caller holds the section row lock).
func replaceMeetings(ctx context.Context, tx *sql.Tx, uni, sectionID string, ms []MeetingInput) error

// parseSlots parses an import cell (L1b); "" or only separators -> nil, "". bad is the row message.
func parseSlots(cell string) (ms []MeetingInput, bad string)
```

`checkMeeting` messages:

| Field | Condition | Message |
|---|---|---|
| `weekday` | not 1..7 | `must be between 1 and 7` |
| `startsAt` | `!hm` | `must be a time HH:MM` |
| `endsAt` | `!hm` | `must be a time HH:MM` |
| `endsAt` | both `hm`, `EndsAt <= StartsAt` | `must be after startsAt` |
| `location` | contains NUL | `must not contain NUL` |
| `location` | over 100 runes after trim | `must be at most 100 characters` |

`hm` requires exactly 5 bytes, so `9:00`, `10:00:00`, `24:00` and `""` fail. Ceiling: no slot crosses midnight and nothing ends at 24:00 (23:59 is the latest).

SQL:

```sql
-- insertMeetings: $1 uni, $2 uuid[] sections, $3 int[] weekdays ([]int32), $4/$5 text[] times, $6 text[] locations
insert into section_meetings (university_id, section_id, weekday, starts_at, ends_at, location)
select $1, s, w, a::time, b::time, l from unnest($2::uuid[], $3::int[], $4::text[], $5::text[], $6::text[]) as x(s, w, a, b, l)
-- replaceMeetings, before insertMeetings
delete from section_meetings where section_id = $1
```

`parseSlots` (L1b): split on `;`, trim each part, skip empty parts. More than 20 non-empty parts: `at most 20 meetings`. Each part must match

```go
var slotRe = regexp.MustCompile(`^([A-Za-z]+)\s+([0-9:]+)\s*-\s*([0-9:]+)\s*(?:@(.*))?$`)
var weekdayOf = map[string]int{"mon": 1, "tue": 2, "wed": 3, "thu": 4, "fri": 5, "sat": 6, "sun": 7}
```

| Failure | Row message |
|---|---|
| no regexp match | `meeting "<part>" must look like Mon 10:00-11:15 @ Room 101` |
| `strings.ToLower(group 1)` not in `weekdayOf` (only the 3-letter forms) | `meeting "<part>": unknown weekday <group 1>` |
| first error of `checkMeeting` | `meeting "<part>": <field> <message>`, e.g. `meeting "Mon 11:00-10:00": endsAt must be after startsAt` |

Location is group 4 trimmed (`@` with nothing after it means `""`). Result goes through `sortMeetings`. Ceiling: a location cannot contain `;`. Grammar examples: `Mon 10:00-11:15 @ Room 101; Wed 10:00-11:15` → two rows, second location `""`; `MON 10:00 - 11:15` ok; `Mon 10:00-11:15 Room 101` is a grammar error.

Not validated, on purpose: overlapping or duplicate slots inside one section (spec does not forbid them; the web shows clashes).

## 4. Wiring in the existing files

### 4.1 `section.go` (L1a)

- `Section` gains `Meetings []Meeting \`json:"meetings"\`` after `PendingStaff`.
- `sectionAudit` gains `Meetings []MeetingInput \`json:"meetings"\`` (always non-nil when written).
- `sectionCols`: append `,\n\t` + `meetingsJSON` after the pending-staff subquery (so `extra` columns stay trailing).
- `handler.go` `scanSection`: add `&meetings` (a `[]byte`) after `&pending` in `dest`; set `s.Meetings = []Meeting{}`; `json.Unmarshal(meetings, &s.Meetings)`.
- `loadForWrite`: select `` `+meetingsJSON+` `` as a sixth column into a `[]byte`, unmarshal into `a.Meetings` (initialised `[]MeetingInput{}`; the `id` key is ignored by `json.Unmarshal`). The `for update of s` stays; the subquery does not lock meetings, the section row lock serialises writers.
- `sectionFields` signature becomes `(courseID, termID, number string, create bool) (string, []httpx.FieldError)`; callers build the error.
- `createSection`: decode `struct { CourseID, TermID, Number string; Meetings []MeetingInput }`. `number, d := sectionFields(...)`; `ms, md := validateMeetings(in.Meetings)`; `d = append(d, md...)`; `len(d) > 0` → `httpx.Validation(d...)`. Then the existing course lookup, `CanManageDepartment`, insert. After the insert: `insertMeetings(ctx, tx, s.UniversityID, repeat(a.ID, len(ms)), ms)` (build the `secs` slice inline), `a.Meetings = ms`, audit, `readSection`.
- `updateSection`: decode `struct { Number tenant.OptStr; Meetings *[]MeetingInput }`. `PatchNulls(number)` as today. `!in.Number.Set && in.Meetings == nil` → `tenant.NoFields()`. Collect errors: number (only when `Set`) plus `validateMeetings(*in.Meetings)` (only when non-nil); one `httpx.Validation`. `after := before`; if `Number.Set`: existing `update sections` and `after.Number`; if `Meetings != nil`: `replaceMeetings`, `after.Meetings = ms`. Audit `before`/`after` as today (both now carry `meetings`).
- `deleteSection`: unchanged code; `before.meetings` comes from `loadForWrite`; rows cascade.

Order of authorisation vs validation stays as today (create validates first, update authorises first).

### 4.4 Import column (L1b): `import.go`

- `sectionsImport`: `Optional: []string{"instructoremails", "taemails", "meetings"}`.
- `sectionRef` gains `Meetings []MeetingInput`.
- `sectionClassifier`: after `pendSet`, `hasMeet, err := idSet(ctx, tx, `select distinct section_id::text from section_meetings where section_id = any($1::uuid[])`, secIDs)`; pass `hasMeet` to `classifySection` (new last parameter).
- `classifySection`, after the "listed as both" loop and before building `ref`: `ms, bad := parseSlots(d["meetings"])`; `bad != ""` → `verr(bad)`. After the staff loop:

```go
addMeet, keepMeet := false, false
if len(ms) > 0 {
	switch {
	case ref.SectionID == "":
		ref.Meetings = ms
	case hasMeet[ref.SectionID]:
		keepMeet = true // D31/D39: never overwrite meetings (an admin may have edited them)
	default:
		ref.Meetings, addMeet = ms, true
	}
}
var notes []string
if invite || addStaff { notes = append(notes, "adds staff") }
if addMeet { notes = append(notes, "adds meetings") }
if keepMeet { notes = append(notes, "keeps meetings") }
msg := ""
if ref.SectionID != "" && len(notes) > 0 { msg = "section exists; " + strings.Join(notes, "; ") }
switch {
case invite:
	return Verdict{Invite, msg, ref}
case ref.SectionID == "" || addStaff || addMeet:
	return Verdict{Add, msg, ref}
}
return Verdict{Action: Exists, Message: msg}
```

  This keeps today's message `section exists; adds staff` byte-for-byte when no meetings are involved.
- `sectionApplier`:
  - Before the section insert, `meetOf := map[string][]MeetingInput{}` keyed `course|term|number` from every row's `ref.Meetings`.
  - In the new-section audit loop: `a.Meetings = meetOf[key]`, or `[]MeetingInput{}` when nil.
  - After the section insert (so `secOf` is complete) and before staff: build `secs`/`ms` from every row with `len(ref.Meetings) > 0`, one `insertMeetings`. For rows with `ref.SectionID != ""` and meetings, also write `section.update` audit entries (`audit.WriteMany`) with `before = sectionAudit{ID, CourseID, TermID, Number, Meetings: []MeetingInput{}}` and `after` the same with `ref.Meetings`.
- Ceiling: classify and apply are not locked against a concurrent hand edit of the same existing section between classify and insert (the PATCH path holds the row lock, the import does not); the worst case is the union of both lists. Fix when seen: `select ... for update` the existing section ids in the classifier on commit.

## 7. Simplifications and their ceilings

| Simplification | Ceiling | Upgrade |
|---|---|---|
| `json_agg` subquery per section row | a page of 200 sections runs 600 indexed subqueries in one statement; fine well past campus scale | lateral join or batched second query if a profile shows it |
| `q` is `ILIKE '%…%'`, no index | sequential scan of one university's courses; fine to tens of thousands | `pg_trgm` GIN on `code`, `title` (an extension; owner's call) |
| `null` meetings on PATCH = absent | indistinguishable from omitted | custom `UnmarshalJSON` with a strict inner decoder |
| HH:MM only, no midnight crossing, no 24:00 | night classes past 23:59 cannot be stored | spec §8 date-range work |
| list masks `pendingStaff` for all plain members, including staff of that row | an instructor sees pending TAs on the section page, not in the catalog list | a per-row `exists` in `sectionCols` if asked |
| import does not lock existing sections | concurrent hand edit + import can leave the union of both lists | `for update` on the classified section ids at commit |
| location cannot contain `;` in the CSV | rare room names | quoted slot syntax |
