# P1-L2 design: tenant scope, `authz`, departments, terms, memberships, invitations, audit-log route

Inputs: spec §4–§6, §8; plan Task 6 (and Task 10 interfaces); contract design `docs/design/P0-L4.md` (wins on every shape, code, route); auth design `docs/design/P1-L1.md`. Packages built here: `apps/api/internal/authz`, `apps/api/internal/tenant`. Stdlib + pgx (`database/sql` via the pgx stdlib driver, as `pg` does) only.

## 0. Deviations from the plan's Task 6 interface (all deliberate)

| Plan | Here | Why |
|---|---|---|
| `tenant.Middleware(db) func(http.Handler) http.Handler` | `tenant.Wrap(d Deps, h tenant.Handler) httpx.Handler` (§1) | `httpx.Router.Handle` takes an `httpx.Handler`, not an `http.Handler` chain. The wrapper also opens the tenant tx and passes it as an argument, so a handler cannot forget it. |
| handler writes the response | `tenant.Handler` **returns** `(status, body, error)`; `Wrap` writes JSON **after commit** | No 201 can reach the client for a transaction that then fails to commit. |
| `CreateInvitation(ctx, tx, universityID, email, role, deptIDs, mailer, baseURL)` | `CreateInvitation(ctx, tx, in NewInvitation, m auth.Mailer, baseURL string)` with `ActorUserID` in `in`; it writes its own audit row | Same call for API, CLI (no actor → `""`), Task 10 staff add and imports; every invitation is audited exactly once. |
| `Department.CreatedAt` in JSON | not serialised (contract decision 7) | Contract wins. `createdAt` is still selected for the cursor. |
| `GET /departments` "admin" (spec §6) | readable by **any active member**; writes admin-only | dept_admins need department names for course forms (Task 10/11). Escalated to the orchestrator; reverting is one `IsAdmin` check. |

## 1. Request pipeline (`tenant/middleware.go`)

```go
package tenant

type Deps struct {
    DB       *sql.DB
    Sessions *auth.SessionStore
    Mailer   auth.Mailer
    BaseURL  string // cfg.BaseURL, used for invitation URLs
}

// Handler is a tenant-scoped handler. tx is the request's only transaction (RLS = s.UniversityID).
// Return (status, body, nil) on success; body nil means no body (204). Return an error to roll back.
type Handler func(r *http.Request, tx *sql.Tx, s authz.Scope) (status int, body any, err error)

func Wrap(d Deps, h Handler) httpx.Handler
func UniversityID(ctx context.Context) string // "" outside Wrap
```

`Wrap(d, h)` returns `func(w, r) error` doing, in order:

1. **Actor.** `a, err := auth.Authenticate(w, r, d.Sessions)` (request to P1-L1, §11) — the same helper `RequireSession` uses: reads cookie, slides it, calls `httpx.WithUserID`. Error → return it (401 `unauthenticated`). Actor first, so an anonymous caller cannot probe which slugs exist.
2. **Slug → university (platform tx, short).** `slug := r.PathValue("slug")`; `pg.WithPlatformTx(ctx, d.DB, …)`: `select id from universities where slug = $1`. `sql.ErrNoRows` → `httpx.NotFound("university")`. Then `httpx.WithUniversityID(ctx, uniID)`.
3. **Tenant tx (the only one the handler sees).** `pg.WithTx(ctx, d.DB, uniID, func(tx) error { … })`:
   1. Scope load (RLS already restricts to `uniID`, so a membership of the same user in B is invisible — Review Focus 2):
      ```sql
      select m.role,
             coalesce((select json_agg(da.department_id order by da.department_id)
                       from department_admins da where da.user_id = m.user_id), '[]')
      from memberships m
      where m.user_id = $1 and m.status = 'active'
      ```
      No row → `httpx.Forbidden()` (403; covers "member of B only" and `invited`). Scan the json into `[]byte`, `json.Unmarshal` into `[]string` (helper `scanIDs`, §1.1).
   2. `s := authz.Scope{UniversityID: uniID, UserID: a.UserID, Role: authz.Role(role), DeptIDs: ids}`; `ctx = withScope(ctx, s)` (also makes `UniversityID(ctx)` and `authz.ScopeFromContext` work); call `status, body, err = h(r.WithContext(ctx), tx, s)`. Error → return it (rollback).
4. After `WithTx` returns nil (committed): `body == nil` → `w.WriteHeader(status)`; else `httpx.WriteJSON(w, status, body)`. Any error from steps 1–3 is returned to `httpx.H`/the router, which calls `httpx.WriteError`.

Context key: `authz` owns it (`type ctxKey struct{}`; `authz.WithScope(ctx, s) context.Context` exported for `tenant` only; `ScopeFromContext` reads it). `tenant.UniversityID(ctx)` = `s.UniversityID` from that scope. One key, one source of truth.

Status matrix: no/expired session 401 → unknown slug 404 → no active membership 403 → route rule 403 → entity id unknown 404. A signed-in user can tell "slug exists, not mine" (403) from "no such slug" (404); slugs are public (sign-in page takes them), accepted.

Every route below is registered as `r.Handle(method, "/api/v1/universities/{slug}/…", Wrap(d, handler))`. Path ids: `id := r.PathValue("id")`; not matching the plan's uuid regexp → `httpx.NotFound(<entity>)` (a malformed id is an unknown id; no 400).

### 1.1 Shared helpers (`tenant/handler.go`)

- `isUUID(s string) bool` (same regexp as plan Global Constraints; `httpx`'s is unexported — copy it, one line).
- `scanIDs(b []byte) ([]string, error)` → `json.Unmarshal`; result never nil (`[]string{}`).
- Arrays **into** SQL: pass `[]string` directly as `$n::uuid[]` (pgx stdlib encodes slices). Arrays **out of** SQL: always `to_json(col)` / `json_agg(...)` scanned via `scanIDs` (no pgtype import).
- `page(r) (httpx.Page, after time.Time, afterID any, err)`: `httpx.ParsePage`; when `p.Cursor != ""` use `p.After()`, else `afterID = nil`. Keyset clause, used by every list here: `where ($1::timestamptz is null or (created_at, id) > ($1, $2::uuid)) order by created_at, id limit $3` with `$3 = p.Limit + 1`; if `limit+1` rows came back, drop the last and set `NextCursor = httpx.NextCursor(lastKept.createdAt, lastKept.id)`. `items` initialised to `[]T{}`.
- `trimLen(field, v string, max int) (string, *httpx.FieldError)`: `strings.TrimSpace`; `""` → `{field, "is required"}`; `utf8.RuneCountInString > max` → `{field, "must be at most <max> characters"}`.
- `noFields() error` → `httpx.Validation(httpx.FieldError{Field: "", Message: "no fields to update"})`.
- Validation collects all field errors of a body, then returns `httpx.Validation(details...)` once (details in body field order).
- `audit.Write(ctx, tx, s.UniversityID, audit.Entry{ActorUserID: s.UserID, Action, EntityType, EntityID, Before, After})` — `Before`/`After` are the JSON resource structs below (nil on create/delete respectively).
- PATCH bodies decode into structs of pointers (`*string`, `*[]string`); `httpx.DecodeJSON` already rejects unknown fields.

## 2. `authz` (`authz/authz.go`)

```go
package authz
type Role string
const (Admin Role = "admin"; DeptAdmin Role = "dept_admin"; Member Role = "member")
type Scope struct { UniversityID, UserID string; Role Role; DeptIDs []string } // DeptIDs only for dept_admin
func WithScope(ctx context.Context, s Scope) context.Context
func ScopeFromContext(ctx context.Context) (Scope, bool)
func IsAdmin(s Scope) bool                                 // s.Role == Admin
func CanManageDepartment(s Scope, deptID string) bool      // admin, or dept_admin with deptID in DeptIDs (slices.Contains)
func CanInvite(s Scope, role Role) bool                    // admin: any; dept_admin: role == Member; member: false
func CanManageSection(ctx context.Context, tx *sql.Tx, s Scope, sectionID string) (bool, error)
func CanManageTAs(ctx context.Context, tx *sql.Tx, s Scope, sectionID string) (bool, error)
func CanReadSection(ctx context.Context, tx *sql.Tx, s Scope, sectionID string) (bool, error)
func CanReadRoster(ctx context.Context, tx *sql.Tx, s Scope, sectionID string) (bool, error)
```

SQL (tx is the tenant tx; RLS confines every row to the university):
- `CanManageSection`: admin → `true` (no query). dept_admin → `select c.department_id from sections s join courses c on c.id = s.course_id where s.id = $1`; `ErrNoRows` → `false, nil`; else `CanManageDepartment(s, deptID)`. member → `false`.
- `CanManageTAs`: `CanManageSection` true → true; else `select exists(select 1 from section_staff where section_id = $1 and user_id = $2 and role = 'instructor')`.
- `CanReadRoster`: `CanManageSection` true → true; else `select exists(select 1 from section_staff where section_id = $1 and user_id = $2)`.
- `CanReadSection`: `CanManageSection` true → true; else `select exists(select 1 from section_staff where section_id = $1 and user_id = $2) or exists(select 1 from enrollments where section_id = $1 and user_id = $2)`.

Rule for callers (Task 10): predicates return `false` for a section that does not exist; handlers load the entity first (404), then call the predicate (403). Role (membership) and staff rows are independent: a dept_admin who is instructor on a section outside their departments can manage its TAs.

Truth table pinned by `authz_test.go` (section S in department D; "dept_admin-in" administers D, "-out" administers only D2):

| Predicate (arg) | admin | dept_admin-in | dept_admin-out | instructor on S | ta on S | student in S | unrelated member |
|---|---|---|---|---|---|---|---|
| IsAdmin | T | F | F | F | F | F | F |
| CanManageDepartment(D) | T | T | F | F | F | F | F |
| CanInvite(member) | T | T | T | F | F | F | F |
| CanInvite(dept_admin), CanInvite(admin) | T | F | F | F | F | F | F |
| CanManageSection(S) | T | T | F | F | F | F | F |
| CanManageTAs(S) | T | T | F | T | F | F | F |
| CanReadSection(S) | T | T | F | T | T | T | F |
| CanReadRoster(S) | T | T | F | T | T | F | F |

Plus: every tx predicate on a random uuid returns `(false, nil)` for a non-admin; a section of university B (inserted under `WithTx(B)`) is invisible → dept_admin of A gets `false`.

## 3. Resources and JSON (contract §3.3)

```go
type Department struct { ID string `json:"id"`; Name string `json:"name"`; Code string `json:"code"`; createdAt time.Time }
type Term struct { ID string `json:"id"`; Name string `json:"name"`; StartsOn string `json:"startsOn"`; EndsOn string `json:"endsOn"`; createdAt time.Time }
type Membership struct { ID string `json:"id"`; UserID string `json:"userId"`; Email string `json:"email"`; DisplayName string `json:"displayName"`; Role authz.Role `json:"role"`; Status string `json:"status"`; DepartmentIDs []string `json:"departmentIds"`; createdAt time.Time }
type Invitation struct { ID string `json:"id"`; Email string `json:"email"`; Role authz.Role `json:"role"`; DepartmentIDs []string `json:"departmentIds"`; ExpiresAt time.Time `json:"expiresAt"`; AcceptedAt *time.Time `json:"acceptedAt,omitempty"`; createdAt time.Time }
```
Unexported `createdAt` is for the cursor only. Times are `.UTC()` before encoding. Dates are read with `to_char(starts_on, 'YYYY-MM-DD')`. `Term` is consumed by Task 10 (`Section.term`).

## 4. Routes

All paths are `/api/v1/universities/{slug}` + suffix. "Std" = the §1 pipeline's 401/403/404. Audit `action` = `<entityType>.<create|update|delete>`.

### 4.1 Departments (`department.go`)

Validation: `name` → `trimLen("name", v, 100)`. `code` → no trimming; must match `^[A-Z0-9]{2,10}$` else `{code, "must be 2 to 10 uppercase letters or digits"}`; missing on create → `{code, "is required"}`.

| Route | Who | SQL | Result |
|---|---|---|---|
| GET `/departments` | any active member | `select id, name, code, created_at from departments where <keyset> order by created_at, id limit $3` | 200 `List[Department]` |
| POST `/departments` | `IsAdmin` else 403 | `insert into departments (university_id, name, code) values ($1,$2,$3) returning id, created_at` | 201 `Department`; audit `department.create` after=Department |
| PATCH `/departments/{id}` | admin | `select id, name, code, created_at from departments where id = $1 for update` (no row → 404 "department not found"); merge; validate merged; `update departments set name=$2, code=$3, updated_at=now() where id=$1` | 200 `Department`; audit `department.update` before/after |
| DELETE `/departments/{id}` | admin | `delete from departments where id = $1 returning id, name, code` (0 rows → 404); then `update invitations set department_ids = array_remove(department_ids, $1::uuid), updated_at = now() where accepted_at is null and $1::uuid = any(department_ids)` | 204; audit `department.delete` before=Department |

Errors: insert/update `pg.MapError` → `pg.ErrConflict` → `httpx.Conflict("department code already exists")`. Delete uses `pg.MapDeleteError`; `ErrConflict` → `httpx.Conflict("department is still in use")` (courses or department admins reference it; FKs are `restrict`). The `invitations` trim answers P1-L1's request: a pending invitation never points at a deleted department, so `SignIn` cannot fail on that FK. A trimmed `dept_admin` invitation may end with `[]` — the invitee becomes a dept_admin of nothing until an admin edits them (ceiling, accepted).

### 4.2 Terms (`term.go`)

Validation: `name` → `trimLen("name", v, 100)`. `startsOn`, `endsOn` → `time.Parse("2006-01-02", v)` else `{field, "must be a date YYYY-MM-DD"}`, missing on create → `{field, "is required"}`. When both parse (merged values on PATCH): `endsOn <= startsOn` → `{endsOn, "must be after startsOn"}`.

| Route | Who | SQL | Result |
|---|---|---|---|
| GET `/terms` | any active member | `select id, name, to_char(starts_on,'YYYY-MM-DD'), to_char(ends_on,'YYYY-MM-DD'), created_at from terms where <keyset> order by created_at, id limit $3` | 200 `List[Term]` |
| POST `/terms` | admin | `insert into terms (university_id, name, starts_on, ends_on) values ($1,$2,$3::date,$4::date) returning id, created_at` | 201; audit `term.create` |
| PATCH `/terms/{id}` | admin | select … `for update` (404 "term not found"), merge, validate, `update terms set name, starts_on, ends_on, updated_at = now()` | 200; audit `term.update` |
| DELETE `/terms/{id}` | admin | `delete from terms where id = $1 returning …` via `pg.MapDeleteError` | 204 / 409 `"term is still in use"`; audit `term.delete` |

Conflict on insert/update → `"term name already exists"` (requires `unique (university_id, name)`, request to P0-L2 §11: section import resolves `termName`, so names must be unique). Order is creation order (contract), not `startsOn`.

### 4.3 Memberships (`membership.go`)

List SQL (admin only):
```sql
select m.id, m.user_id, u.email, u.display_name, m.role, m.status, m.created_at,
       coalesce((select json_agg(da.department_id order by da.department_id)
                 from department_admins da where da.user_id = m.user_id), '[]')
from memberships m join users u on u.id = m.user_id
where ($1::timestamptz is null or (m.created_at, m.id) > ($1, $2::uuid))
order by m.created_at, m.id limit $3
```
`getMembership(ctx, tx, id, forUpdate bool)` is the same select with `where m.id = $1` (+ `for update of m`).

**Body `MembershipUpdate`**: `role` required, one of the three → else `{role, "must be one of admin, dept_admin, member"}` (missing → `{role, "is required"}`). `departmentIds` optional, default `[]`; each must be a uuid else `{departmentIds, "must contain only ids"}`; deduplicate; `role == dept_admin && len == 0` → `{departmentIds, "is required for dept_admin"}`; `role != dept_admin && len > 0` → `{departmentIds, "must be empty unless role is dept_admin"}`. Existence: `select count(*) from departments where id = any($1::uuid[])` ≠ len → `httpx.NotFound("department")`.

**Last-admin rule, race-safe.** Every membership mutation (PATCH, DELETE) first runs
```sql
select 1 from universities where id = $1 for no key update
```
which serialises membership changes per university (`for no key update` does not block FK `key share` locks, so other writes in the university are unaffected; `universities` has no RLS). Then, if the target is an active `admin` and the change removes it (new role ≠ admin, or delete): `select count(*) from memberships where role = 'admin' and status = 'active'` = 1 → `httpx.Conflict("university must keep one admin")`. `SignIn` only ever raises roles, so it cannot break the invariant concurrently.

| Route | Steps | Result |
|---|---|---|
| GET `/memberships` | `IsAdmin` else 403; list | 200 `List[Membership]` |
| PATCH `/memberships/{id}` | admin; validate body; lock university; `getMembership(forUpdate)` (404 "membership not found"); dept existence; last-admin check; `update memberships set role=$2, updated_at=now() where id=$1`; `delete from department_admins where user_id = $1 and not (department_id = any($2::uuid[]))` (with `$2 = '{}'` when not dept_admin, so demotion clears all rows); `insert into department_admins (university_id, department_id, user_id) select $1, d, $2 from unnest($3::uuid[]) d on conflict (department_id, user_id) do nothing`; re-read | 200 `Membership`; audit `membership.update` before/after |
| DELETE `/memberships/{id}` | admin; lock; read (404); last-admin check; `delete from department_admins where user_id = $1`; `delete from memberships where id = $1` | 204; audit `membership.delete` before |

An admin may change their own role or remove themselves; the last-admin rule is the only guard (smallest; the web can warn). Removing a membership leaves the user's `section_staff`/`enrollments` rows in place: the middleware already denies them, rosters still list them (ceiling: Task 10 may decide to cascade; re-adding the member restores access with no data loss).

### 4.4 Invitations (`invitation.go`)

```go
type NewInvitation struct {
    UniversityID, ActorUserID string // ActorUserID "" for the CLI
    Email         string             // raw; normalised inside
    Role          authz.Role
    DepartmentIDs []string
}
var (
    ErrAlreadyMember     = httpx.Conflict("user is already a member")
    ErrInvitationPending = httpx.Conflict("invitation already pending for this email")
)
func CreateInvitation(ctx context.Context, tx *sql.Tx, in NewInvitation, m auth.Mailer, baseURL string) (Invitation, error)
```
`CreateInvitation` (tx must be `pg.WithTx(in.UniversityID)`; it does **no** authorisation — callers check `authz.CanInvite`):
1. `email, err := auth.NormalizeEmail(in.Email)` → error: `{email, "must be a valid email"}`. Role and `departmentIds` validated exactly as `MembershipUpdate` (field names `role`, `departmentIds`), collected into one `httpx.Validation`. Department existence → 404 as §4.3.
2. `select exists(select 1 from memberships m join users u on u.id = m.user_id where u.email = $1)` → `ErrAlreadyMember` (any status).
3. `select exists(select 1 from invitations where email = $1 and accepted_at is null and expires_at > now())` → `ErrInvitationPending`. Expired pending invitations do not block. Callers compare with `errors.Is` (Task 10's staff add uses it to attach to the existing invitation instead).
4. `token, hash := auth.NewToken()`; `insert into invitations (university_id, email, role, department_ids, token_hash, expires_at) values ($1,$2,$3,$4::uuid[],$5, now() + interval '14 days') returning id, expires_at, created_at`.
5. `audit.Write(… Action "invitation.create", EntityType "invitation", After: inv)`.
6. `select name from universities where id = $1`; `m.Send(ctx, email, "You are invited to "+name+" on UniCourse", text)` with text (each line `\n`, URL alone on its line):
   ```
   You have been invited to join <name> on UniCourse as <role>.

   Accept the invitation:
   <auth.InvitationURL(baseURL, token, email)>

   This invitation expires on <expiresAt UTC, 2006-01-02>.
   ```
   Send error → returned (rollback, 500). Mail is sent inside the tx, before commit (ceiling: a commit failure after send leaves a dead link; a slow SMTP holds the tx).

Duplicates: a second invite for a pending email is 409, not a refresh (contract lists 409; refresh would silently re-mail). Two concurrent creates for the same email can both succeed (no lock); harmless because `SignIn` accepts both and keeps the higher role (ceiling, accepted).

| Route | Who | Steps | Result |
|---|---|---|---|
| GET `/invitations` | admin: all; dept_admin: `role = 'member'` only; member: 403 | `select id, email, role, to_json(department_ids), expires_at, accepted_at, created_at from invitations where ($4 or role = 'member') and <keyset> order by created_at, id limit $3` (`$4` = `IsAdmin`) | 200 `List[Invitation]` (pending, expired and accepted all listed) |
| POST `/invitations` | admin, dept_admin | `s.Role == member` → 403; decode `{email, role, departmentIds?}`; if `role` is one of the three values and `!authz.CanInvite(s, role)` → 403 (before field validation); `CreateInvitation` with `ActorUserID: s.UserID` | 201 `Invitation` |
| DELETE `/invitations/{id}` | admin, dept_admin (member 403) | `select role, accepted_at, … from invitations where id = $1 for update` (404 "invitation not found"); `!CanInvite(s, role)` → 403; `accepted_at` set → `httpx.Conflict("invitation already accepted")`; `delete from invitations where id = $1` (`pending_section_staff` cascades) | 204; audit `invitation.delete` before |

### 4.5 Audit log (`handler.go`)

GET `/audit-log`, admin only. Query params → `audit.Filter`: `entityType` must be one of `department, term, membership, invitation, course, section, staff, enrollment` else `{entityType, "must be one of department, term, membership, invitation, course, section, staff, enrollment"}`; `entityId`, `actorUserId` uuid else `{<param>, "must be a uuid"}`; `from`, `to` `time.Parse(time.RFC3339, v)` else `{<param>, "must be an RFC 3339 date-time"}`. `httpx.ParsePage` runs first and its error is returned as is; otherwise all filter errors are collected into one `httpx.Validation` in the order entityType, entityId, actorUserId, from, to. `audit.List(ctx, tx, f, p)` → 200 (newest first; P0-L2 owns order and cursor).

## 6. Test strategy

All integration tests: `db := testdb.Open(t)`; `fx := testdb.Seed(t, db)`; extra rows inserted with `pg.WithTx(ctx, db, uni, …)` (tenant rows) or `pg.WithPlatformTx` (users). HTTP tests build the real chain: `r := httpx.NewRouter(); tenant.Register(r, deps)` wrapped by `httpx.RequestIDMiddleware`/`Recover` as `main` does, served with `httptest.NewServer`; session cookie `unicourse_session` from `(&auth.SessionStore{DB: db}).Create(ctx, userID)`; mailer = `auth.LogMailer` over a `slog.NewJSONHandler(&buf, nil)` so tests parse the `"msg":"mail"` line (P1-L1 §8). Shared test helpers in `tenant/helpers_test.go`: `newServer(t) (*httptest.Server, fx, *bytes.Buffer)`, `user(t, uni, role, deptIDs...) (userID, cookie)`, `do(t, srv, cookie, method, path, body) (status int, raw []byte)`, `errBody(raw) (code string, details []httpx.FieldError)`. Response shapes are checked by decoding into the §3 structs with `DisallowUnknownFields` plus key-presence checks for required arrays (`departmentIds` present when empty).

## 7. Simplifications and ceilings

- One platform tx + one tenant tx per request (2 round-trip groups). Ceiling: cache slug → id when latency matters.
- Responses written after commit; handlers cannot stream. Ceiling: a streaming export endpoint needs its own wrapper.
- Membership changes serialise per university (row lock). Ceiling: fine until thousands of concurrent role edits per university.
- No lock on invitation creation; duplicate pending invitations possible under a race (harmless).
- Mail sent synchronously inside the tx.
- Removing a member keeps their staff/enrollment rows.
- Malformed path id → 404, not 400.
