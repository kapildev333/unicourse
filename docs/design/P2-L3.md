# P2-L3 design: web `courses` and `my-sections` features

Builds on (binding): shared web layer `docs/design/P1-L4.md` §1–§2, §4–§6, §8 (tokens, Button/Table/Dialog/FormField recipes, PageHeader, EmptyState, ErrorBanner, StatusMessage, Badge/RoleBadge/roleLabel, LoadMore, Loading, FormErrors/useFieldErrors/useFocusFirstError/errorMessage, useCursorList, formatDate, useMe/useUniversity, `test-utils.tsx`); contract `docs/design/P0-L4.md` §2, §3.4, §3.5, §5.3, §6, **as amended by the orchestrator** (relay, 2026-10-06): `Section.pendingStaff: { email, role }[]` (required, may be empty); read/write rules below in §0.2; `deleteSection` never 409 (cascades); `deleteCourse` 409 = "still has sections".
Hard limits: no new dependencies; no `fetch` outside `src/api/`; no `window.confirm()`; only P1-L4 colour roles. Everything below is under `apps/web/`.

## 0. Decisions and deviations

### 0.1 Deviations from plan Task 11 (deliberate)
1. **`CsvImportDialog` props** are `{ open, onClose, title, target, columns, onDone }`, not `{ previewUrl, importUrl, columns, onDone }`: URLs as strings bypass the typed client. `target` is a discriminated union resolved to literal paths inside `src/api/upload.ts` (§4.1).
2. **`StaffEditor` props** add `slug` and `pendingStaff`: `{ slug, sectionId, staff, pendingStaff, canManageInstructors, canManageTAs }`.
3. **No `courses/$courseId.tsx`**: a course has no screen of its own (edit is a dialog on the list; its sections are on the section list). Instead `courses/sections.tsx` (section list) sits next to `courses/index.tsx` under a `courses.tsx` layout with two tabs. Spec routing `/{slug}/courses/*` holds.
4. **Role choice in the staff form is per-role submit buttons** ("Add instructor", "Add TA"), not a `<select>`: one fewer control, the forbidden option simply does not render, and the button text states the outcome. Same limiting rule as a select.
5. **Extra files**: `src/api/upload.ts`, `src/features/courses/{access.ts,access.test.ts,queries.ts,courses-layout.tsx,course-dialog.tsx,section-dialog.tsx,remove-dialog.tsx}`, `src/features/courses/section-list.test.tsx`, `src/features/courses/roster.test.tsx`. `Dialog` gains `wide?: boolean`.
6. Pages take `slug` and search-param values as **props** (P1-L4 §0.3); route files wire params and `navigate`.

### 0.2 Access rules the UI mirrors (display only; the server enforces)
| Action | admin | dept_admin of the course's department | section instructor | section TA | enrolled student |
|---|---|---|---|---|---|
| Courses nav, course list, section list (read) | yes | yes (every course/section of the university, P2-L2 §2) | no | no | no |
| Section detail (read) | yes | yes | yes | yes | yes |
| Add/remove instructor | yes | yes | no | no | no |
| Add/remove TA | yes | yes | yes | no | no |
| Read roster | yes | yes | yes | yes | **no (not rendered, not fetched)** |
| Remove roster row, import roster | yes | yes | no | no | no |
| Course/section create/edit/delete/import | yes | yes (own departments only; rows of other departments show no Edit/Delete) | no | no | no |

A dept_admin of another department gets 403 on that section's detail (P2-L2 §2); the UI shows the 403 state, it does not hide the link.

### 3.6 `CsvImportDialog` — `csv-import-dialog.tsx`
```ts
export function CsvImportDialog(props: { open: boolean; onClose(): void; title: string; target: ImportTarget;
  columns: string[]; hint?: string; onDone(result: ImportPreview): void }): JSX.Element
export function importSummary(kind: ImportTarget['kind'], c: ImportCounts): string
// "Import finished: 12 added, 3 invited, 5 already existed." (omit zero parts except when everything is zero: "Import finished: nothing changed.")
```
`Dialog` with `wide`. State: `file?: File`, `preview?: ImportPreview`, `failed: Map<number, string>` (line → message from a failed commit), `stale: boolean` (checksum mismatch), `previewMut`, `commitMut`. Reset all on open.

**Layout, top to bottom**
1. Template hint (`text-sm text-ink-muted`): "The first line must be a header with these columns:" then `<code className="rounded bg-canvas px-1.5 py-0.5 text-ink">{columns.join(',')}</code>`, then `hint` if given, then `<a download="{kind}-template.csv" href={'data:text/csv;charset=utf-8,' + encodeURIComponent(columns.join(',') + '\n')} className="text-accent underline">Download template</a>`. "Columns are case-insensitive. Maximum 5 MB."
2. `FormField` label "CSV file": `<input type="file" accept=".csv,text/csv" className="text-sm">`. On change with a file: reset preview/failed/stale, run preview immediately (no separate button).
3. Live region (always mounted) `<p role="status" aria-live="polite" className="text-sm">`: "Checking {file.name}…" while previewing; then "{rows.length} rows checked: {add} to add, {invite} to invite, {exists} already exist, {error} with errors." ; after a failed commit "Import failed: {failed.size} rows have errors. Fix the file and choose it again."
4. Errors (`ErrorBanner`, `role="alert"`): preview/commit errors with `field === 'file'` → the detail message sentence-cased under title "This file can't be imported"; `checksum` → title "The file changed since the preview" body "Preview it again before importing." with Button secondary sm "Preview again" (re-runs preview with the same `file`); any other error → `errorMessage(error)`.
5. Counts summary (`<dl className="flex gap-4 text-sm">`): Add n · Invite n · Exists n · Errors n (each term text + number; Errors number in `text-danger font-semibold` when > 0).
6. Preview table in `<div className="max-h-[55vh] overflow-y-auto">`, `Table` caption "Preview of {file.name}": columns Line, Result, Message, then one column per `columns` entry (header text = column name). Cell values `row.data[col.toLowerCase()] ?? ''`. Result = `ActionBadge` (word + colour). Rows with `action === 'error'` or in `failed` get `className="bg-danger-soft"` on the `<tr>` and `text-danger` on the message cell; the meaning is carried by the "Error" badge word, not the colour.
7. Footer (`mt-6 flex items-center justify-between`): left, when Import is disabled, the reason (`text-sm text-ink-muted`, id referenced by the Import button's `aria-describedby`): no file "Choose a file to preview."; errors "Fix the {n} rows with errors and choose the file again."; nothing to do "Nothing to import: every row already exists."; stale "Preview the file again."; right: Cancel (secondary), Import (primary, label "Import {add+invite} rows", "Importing…" while pending).

**Rules**
- Import enabled iff `preview && !stale && failed.size === 0 && counts.error === 0 && counts.add + counts.invite > 0 && !pending`.
- Commit: `commitImport(target, file, preview.checksum)`. 200 → `onDone(result)` (parent closes, shows `importSummary`, invalidates). 400 with `line:N` details → `failed = new Map(details.filter(f startsWith 'line:').map(d => [Number(d.field.slice(5)), sentence(d.message)]))`; displayed rows treat those lines as errors with that message. The dialog then renders an `ErrorBanner` title "Import failed" body "{n} rows have errors; they are marked below and listed first." and focuses it (ref, `tabIndex -1`).
- **Rendering ceiling: 200 rows.** Displayed = rows with `action==='error'` or in `failed` (line order), then the remaining rows in line order, sliced to 200. When `rows.length > 200` a line under the table: "Showing 200 of {rows.length} rows. Rows with errors are listed first." (If errors alone exceed 200: "Showing the first 200 of {n} rows with errors.") The full `rows` array stays in memory (a 50k-row roster ≈ a few MB JSON; acceptable), only the DOM is capped.
- Keyboard path: dialog opens with focus on "Download template" link (first focusable) → Tab to file input → Enter/Space opens the native picker → after choosing, focus remains on the input and the status announces the result → Tab reaches Cancel → Import. Escape closes (native). Closing while a request is pending is allowed; results are ignored after unmount/close (check `open` before setting state).

## 4. Data layer

### 4.1 `src/api/upload.ts`
```ts
export type ImportPreview = components['schemas']['ImportPreview']
export type ImportCounts = components['schemas']['ImportCounts']
export type ImportTarget =
  | { kind: 'courses'; slug: string }
  | { kind: 'sections'; slug: string }
  | { kind: 'enrollments'; slug: string; sectionId: string }
export function previewImport(t: ImportTarget, file: File): Promise<ImportPreview>
export function commitImport(t: ImportTarget, file: File, checksum: string): Promise<ImportPreview>
```
Implementation: build `FormData` (`file`, plus `checksum` on commit); `switch (t.kind)` calls `api.POST` with the literal path (`'/universities/{slug}/courses/import/preview'` etc.) and `params.path`, `body: form as never`, `bodySerializer: (b) => b as FormData`, wrapped in `unwrap`. Do not set `Content-Type` (fetch adds the multipart boundary). Six literal calls, no string building.

### 4.2 Query keys
| Key | Fetch | staleTime |
|---|---|---|
| `[slug,'courses','list',{ departmentId }]` | listCourses pages, limit 50 | 0 |
| `[slug,'courses','all']` | listCourses limit 200, one page (`useAllCourses`) | 60 s |
| `[slug,'terms','all']` | listTerms limit 200, one page (`useAllTerms`) | 60 s |
